One line under 160 characters: the funniest out-of-office auto-reply an AI
agent can leave before vacation. `main.py` (Python 3.13, standard library
only) scores six original candidate replies against the judge's published
criteria — joke first, then machine voice, fit, freshness, and a clean
single line — and writes the winner to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

## Winning line

> Out of office. My inbox just promoted itself to middle management — it now
> schedules meetings about your email, then declines them.
